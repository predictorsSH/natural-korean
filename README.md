# natural-korean

번역어투와 격언조를 걷어내고 쉬운 말로 쓰는 한국어 문체 규칙을 담은 Claude Code 플러그인.

## 설치

```
/plugin marketplace add /Users/sanghyun/Projects/natural-korean
/plugin install natural-korean@natural-korean
```

깃허브에 올린 뒤에는 경로 대신 `owner/repo`를 쓴다.

설치한 뒤 `/output-style` 에서 `자연스러운 한국어`를 고르면 켜진다.

## 들어 있는 것

출력 스타일 `자연스러운 한국어` 하나다. 켜두면 모든 답변에 규칙이 붙는다.
`keep-coding-instructions: true` 라서 코딩 지침은 그대로 두고 문체만 얹는다.

## 규칙 고치기

[output-styles/natural-korean.md](output-styles/natural-korean.md)를 고치면 된다.
