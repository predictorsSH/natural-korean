# natural-korean

## 프로젝트 소개

최근 LLM과 Agent가 작성한 글의 가독성이 떨어지고 부자연스럽다는 느낌을 받고 있다. 여러 기술 블로거도 비슷한 경험을 공유하고 있다.

이에 LLM과 Agent가 작성한 한국어 문장이 얼마나 자연스럽고 읽기 쉬운지 평가할 수 있는 벤치마크를 만들고자 한다. 나아가 평가 결과를 바탕으로 AI가 더 자연스럽고 읽기 쉬운 한국어 글을 작성할 수 있는 방법을 찾고자 한다.

## 목표

1. **글쓰기 능력 평가 환경 구축**
   누구나 자신이 사용하는 모델이나 Agent의 한국어 글쓰기 능력을 손쉽게 평가할 수 있는 환경을 제공한다.

2. **글쓰기 품질 개선 방법 제시**
   평가 결과를 분석해 모델과 Agent가 작성하는 글의 자연스러움과 가독성을 개선할 수 있는 방법을 제안한다.

## 평가 기준

자연스러운 한국어와 읽기 쉬운 글을 객관적으로 판단하기는 쉽지 않다. 따라서 여러 평가 방법을 활용해 글쓰기 품질을 다각도로 측정하고자 한다.

| 평가 기준 | 설명 |
| --- | --- |
| AI 평가 | 한국어 글쓰기 능력이 우수한 AI 모델을 평가자로 활용해 글의 자연스러움과 가독성을 채점한다. |
| 미정 | 관련 연구 및 리서치를 통해 추가 평가 기준을 선정한다. |
